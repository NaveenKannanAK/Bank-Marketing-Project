ABOUT THE PROJECT

Discover BankPulse

Banking Marketing Intelligence & Customer Subscription Prediction — using machine learning to support smarter, data-driven marketing decisions.

Project Overview

BankPulse is a machine learning application designed to predict whether a bank customer is likely to subscribe to a term deposit based on demographic, financial, campaign and economic information.

📊

Dataset Information

Dataset: Portuguese Bank Marketing

Records: 41,176

Input Features: 19 production features

Target Variable: y

🤖

Machine Learning

Selected Model: Random Forest Classifier

Preprocessing: One-Hot Encoding

Scaling: Standard Scaling

Output: Subscription Yes / No

🎯

Project Objective

Identify customers who are more likely to subscribe to a bank term deposit and help marketing teams make informed campaign decisions.

⚙️

Application Features

Customer information input form

Machine learning-based prediction

Subscription probability display

Prediction result and recommendation

Technologies Used

Python Pandas NumPy Scikit-learn Random Forest Flask HTML5 CSS3 JavaScript
